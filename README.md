# E-Commerce Sales & Profit Analysis

## Project Overview
This project analyzes 700 e-commerce transactions to understand sales performance, profitability, product performance, customer types, and regional trends.

## Tools & Technologies
- Microsoft Excel
- PostgreSQL
- SQL
- Power BI

## Key Analysis
- Sales and profit analysis
- Monthly sales trends
- Category-wise performance
- Top 10 products by sales
- Regional sales analysis
- Customer type analysis
- Payment method analysis
- Product profitability
- Discount and profit analysis

## Key Metrics
- Total Orders: 700
- Total Sales: 18.26M
- Total Profit: 3.09M

## Dashboard
An interactive Power BI dashboard was created to visualize sales, profit, products, categories, regions, and customer performance.

## Project Workflow
1. Data cleaning and preparation in Excel
2. Data analysis using PostgreSQL and SQL
3. Dashboard creation using Power BI
4. Business insights from the analyzed data

## Skills Demonstrated
Excel | SQL | PostgreSQL | Power BI | Data Analysis | Data Visualization
